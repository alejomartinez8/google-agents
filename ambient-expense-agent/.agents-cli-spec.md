## Feature: Expense Report Processing

```gherkin
Feature: Expense Report Processing

  Scenario: Low-value expense auto-approval
    Given an expense report with amount: 45
    When the agent processes the report
    Then it auto-approves with no LLM call

  Scenario: High-value expense with PII in the description
    Given an expense report with amount: 250 and an SSN in the description
    When the agent processes the report
    Then it redacts the SSN before the LLM reviewer sees it
    And it routes to human approval after the LLM review
```

---

## Technical Specifications

### 1. Deterministic Bypass (No LLM Call)
- **Condition:** Standard valid expense with `amount < 100.00`.
- **Behavior:** Auto-approves directly in the application pre-routing pipeline without calling Gemini. Zero token cost and sub-10ms response time.

### 2. Pre-LLM Security & PII Redaction
- **Condition:** Any expense requiring cognitive evaluation (`amount >= 100.00` or contextual policies).
- **Behavior:** Before sending the prompt to Gemini, all PII patterns (SSN `\d{3}-\d{2}-\d{4}`, credit cards, etc.) in `description` or metadata are redacted to `[REDACTED_SSN]`.

### 3. Human-in-the-Loop Routing
- **Condition:** High-value expenses (`amount >= 100.00`).
- **Behavior:** The LLM reviews the sanitized payload and routes to `route_to_manager_approval` for human oversight.
